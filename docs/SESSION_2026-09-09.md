## Important development caution

Do not run `npm run build` while `npm run dev` is using the same `.next` cache. It can leave the running dev server with missing generated chunk errors such as `Cannot find module './7787.js'`.

Recovery:

1. Stop the Next dev process.
2. Delete only this project's `.next` directory.
3. Restart with `npm run dev`.
